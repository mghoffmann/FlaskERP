# Full job description
## About the work

We build and run an on-premise ERP platform for regulated manufacturing - Python microservices, Docker, PostgreSQL, and a lightweight HTML/JS operator UI. You'll join a small, disciplined team and ship real features against a live system used on the factory floor.

What makes this role different: you'll do your day-to-day development paired with Claude Code (an Al coding agent). We're looking for someone who is genuinely good at directing an Al agent

- scoping the work, reviewing its output critically, and shipping correct code fast. This skill matters as much to us as raw years of experience.

## You'll be a fit if you have:

- 3-6 years writing production software
- Solid Python; comfortable reading and modifying a large codebase you didn't write
- Real experience with relational databases and schema migrations
- Working knowledge of Docker/docker-compose and Git
- Hands-on experience with Al coding tools (Claude Code, Cursor, Copilot) - and the judgment to know when the Al is wrong
- Discipline around process: test on dev first, verify before deploy, respect security constraints

### Bonus points:

- Manufacturing, ERP, payroll, or accounting domain experience
- Familiarity with regulated data (ITAR/CUI) or a track record of handling sensitive systems responsibly
- Comfort with plain HTML/JS front-end work
